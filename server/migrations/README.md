# Database migrations

Add ordered Goose SQL migrations here as domain tables are introduced. The Phase 1 foundation migration creates restaurant, staff user, membership, server-side session, and audit-log tables. The Phase 2 queue-settings migration adds public table/pickup configuration, and the customer ticket migration adds orders, per-day counters, customer sessions, queues, and secure tickets. Platform onboarding adds administrator and application records; verified owner accounts add email-verification tokens and sessions; owner workspace adds restaurant tables, assignments, staff invitations, and notification history. The Phase 5 migration adds the transactional real-time event outbox. The Phase 6 migration adds encrypted ticket push subscriptions, notification ticket-link ciphertext, and delivery-attempt history. The restaurant-branding migration adds bounded PNG/JPEG logos to applications and approved restaurants. Apply migrations with `go run ./cmd/migrate` from `server/`.
